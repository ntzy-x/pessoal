# 🌐 Perfil GitHub - ntzy-x (Página Web)

Página web desenvolvida como parte de uma **atividade prática de introdução à programação web**. 

O projeto consiste em um cartão de perfil estilizado e responsivo baseado nas informações públicas do perfil do GitHub [@ntzy-x](https://github.com/ntzy-x).

---

## 🚀 Tecnologias Utilizadas

* **HTML5**: Estruturação semântica da página.
* **CSS3**: Estilização moderna inspirada no tema *Dark* do GitHub, utilizando variáveis customizadas, Flexbox e Grid.
* **Google Fonts**: Tipografia utilizando a fonte *Inter*.

---

## ⚙️ Como Executar o Projeto

1. Faça o clone deste repositório ou baixe os arquivos compactados (`.zip`).
2. Certifique-se de que os arquivos `index.html` estão na mesma pasta.
3. Abra o arquivo **`index.html`** diretamente em qualquer navegador web moderno (Google Chrome, Firefox, Edge, etc.).

---

## 📌 Funcionalidades

* Exibição de foto de avatar oficial e dados do perfil.
* Layout responsivo e adaptado para diferentes tamanhos de tela.
* Cartão com efeitos sutis de transição e foco estético (Dark Mode nativo).
* Botão de redirecionamento direto para o perfil original no GitHub.
